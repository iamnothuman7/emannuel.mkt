# Emannuel Marketing

Site de apresentação profissional de Emannuel Mardyan. O projeto reúne apresentação, serviços, habilidades e formas de contato em uma página com HTML, CSS e JavaScript.

[Abrir site no GitHub Pages](https://iamnothuman7.github.io/emannuel.mkt/)

## Interface

O código inclui navegação mobile, títulos animados, efeito de fundo em canvas e transições durante a navegação. Estilos e scripts ficam no próprio `index.html`; `foto.png` contém a imagem de apresentação.

## Executar localmente

```sh
git clone https://github.com/iamnothuman7/emannuel.mkt.git
cd emannuel.mkt
python -m http.server 8000 --bind 127.0.0.1
```

Abra `http://127.0.0.1:8000/`. Python é usado apenas como servidor local; não há dependências de backend ou etapa de build.

## Manutenção

Revise textos comerciais, links de contato e imagens antes de reaproveitar o projeto. Ao editar a interface, confira menu mobile, navegação por teclado, legibilidade e comportamento das animações. O repositório ainda não contém testes automatizados; acessibilidade e desempenho não são certificados por este README.
